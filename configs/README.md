# Спецификация конфигов

## Основной конфиг (benchmark.json)

Содержит 3 основные секции:
1. build - конфигурация построения индексов
1. search - конфигурация поиска на стороне бэкенда
1. measurement - конфигурация бенчмарка и запросной части

Стоит заметить, что ***все поля и секции конфигов***, будь то общий конфиг или для конкрятного бекенда ***являются обязательными***. В репозитории приведены полные конфиги с какими-то значениями, которые вы вольны переопределять.

### build

Настройки построения индекса.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `metric` | `std::string` | Метрика близости векторов: `"l2"` — квадрат евклидова расстояния, `"ip"` — скалярное произведение. Для L2 меньшее значение лучше, для IP — большее. |
| `seed` | `std::uint64_t` | Сид генератора случайных чисел, используемого бэкендом при построении и обучении индекса. |
| `threads` | `std::uint16_t` | Число потоков, выделяемых бэкенду для построения индекса. |

### search

Общие настройки поиска. Специфичные параметры конкретного бэкенда задаются в его отдельном конфиге.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `neighbors_per_query` | `std::uint16_t` | Число ближайших соседей, запрашиваемых для каждого запроса (`k`). |
| `threads` | `std::uint16_t` | Число внутренних потоков бэкенда для обработки одного запроса, если реализация поддерживает такое распараллеливание. |

### measurement

Настройки выполнения и повторения замеров.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `query_threads` | `std::uint16_t` | Число потоков бенчмарка, одновременно вызывающих `Search` у общего экземпляра бэкенда. Каждый вызов обрабатывает один запрос. |
| `warmup_queries_per_worker` | `std::size_t` | Число прогревочных запросов на каждый поток перед замерами. Они не учитываются в итоговых метриках. Значение `0` отключает прогрев. |
| `repetitions` | `std::size_t` | Число повторений измерительного прогона по набору запросов. Повторения используют один построенный индекс. |
| `seed` | `std::uint64_t` | Начальное состояние генератора случайных чисел, задающего порядок запросов в бенчмарке. |

### NB!
Для общего понимания разграничения тредов: при `query_threads = 8` и `search.threads = 1` восемь потоков независимо выполняют поиск, выделяя каждому запросу один внутренний поток бэкенда.
